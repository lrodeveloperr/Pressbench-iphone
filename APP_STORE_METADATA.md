# PressBench App Store metadata

## Positioning

PressBench is the brand-independent production and quality-control log for heat-press operators. It turns a working setup into a repeatable run, catches problems at the first piece, and shows where waste and rework occur.

PressBench is not a design marketplace, machine remote, order-management suite, or universal promise that one heat setting is safe for every blank. Manufacturer presets are editable starting points. The operator confirms the exact instructions and proves the setup on the actual machine and material.

## Description

PressBench helps heat-press operators repeat what works and catch problems before a full production run.

Every press, blank, transfer, and shop behaves differently. Build a setup for the machine you are actually using, start from a sourced preset or a setup you have already proved, then follow each timed stage and record the outcome.

PRODUCTION, NOT GUESSWORK

- Save machine-specific temperature, time, pressure, peel, placement, and stage instructions.
- Use a preset as-is, use it as a base, reuse a saved setup, or enter a setup manually.
- Run a first-piece check before production.
- Follow multi-stage timers from pre-press through finish.
- Record issues, rework, waste, and completed quantities.
- See first-pass yield and waste rate.
- Search complete run history and correct a record with an audit reason.
- Generate PDF and XLSX production reports with PressBench Pro.

BUILT FOR THE PRESS FLOOR

- Works with any brand of heat press.
- Works offline after installation.
- No account, ads, analytics, or tracking.
- Existing local records remain readable without Pro.
- Optional backup and restore through Apple Files.
- Available in 31 app languages.

Two successfully completed and saved runs are included at no charge. PressBench Pro unlocks unlimited runs and PDF/XLSX production reports.

Heat presses and materials vary. Treat every preset as an editable starting point, confirm current instructions for the exact product, and test before production.

## Product-page tests

Run one variable at a time with App Store product page optimization:

1. First screenshot: `Stop problems at the first piece` versus `Repeat the setup that worked`.
2. Subtitle: `Settings, Runs & Waste Tracker` versus `Setups, Runs & Quality Control`.
3. Icon: approved current icon versus a simplified press-and-checkmark concept, if a second approved icon is produced.

Use custom product pages for three acquisition intents:

- HTV and DTF operators: setup reuse, first-piece approval, rework, and waste.
- Sublimation operators: exact multi-stage process, timer, peel/finish, and machine specificity.
- Growing shops: run history, first-pass yield, filters, and PDF/XLSX reports.

Do not change several page elements in the same test. Judge winning variants on product-page conversion, paid conversion, and retained completed runs rather than taps alone.

## Review prompt

Ask only after value has been demonstrated: after a successful completed run with no unresolved issue, or after a successful report export. Never interrupt a timer, first-piece decision, error, correction, purchase, or restore flow.
