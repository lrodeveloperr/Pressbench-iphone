# PressBench iPhone

Production iPhone source for PressBench, using the deterministic v0.21.4 engine with the approved Executive Minimal presentation, approved Pressed Record brand, three-screen onboarding, 31-language localization, canonical legal links, premium report gates, and App Store entitlement boundary.

## CI

- **Validate PressBench iOS** runs on every push/PR.
- **Run TestFlight Build** is manual and fails closed before upload.

See `TESTFLIGHT_SETUP.md` for the one-time Apple secret setup.
